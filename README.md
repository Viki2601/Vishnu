## About

This repository contains my personal portfolio: an interactive, design-led showcase of frontend engineering, UI systems, motion, and selected client and product work.

The experience is built around horizontal navigation, responsive layouts, scroll-driven reveals, and a reactive constellation canvas. It is intentionally visual, but the implementation stays componentized and performance-conscious.

## Highlights

- Interactive hero canvas with a mouse-reactive constellation network
- Horizontal-scroll portfolio with sections for about, journey, certificates, projects, services, and contact
- Framer Motion transitions, spring physics, magnetic interactions, and staggered reveals
- Three.js/WebGL project showcase and a full-screen space video background
- Responsive layouts with custom design tokens, glass surfaces, and neon cyan accents
- Contact form backed by a Next.js route and Resend email delivery
- SEO essentials including metadata, robots, sitemap, and Person structured data

## Run Locally

```bash
git clone https://github.com/Viki2601/Vishnu.git
cd Vishnu
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Environment Variables

The contact API uses Resend. Add the following variable to `.env.local` before testing email delivery:

```env
RESEND_API_KEY=your_resend_api_key
```

## Project Structure

